# 智慧综合治税与税收风险智能分析平台 · 交互说明文档

> 版本 v1.0 · 政务内网 · 适用于本项目全部页面
> 交互遵循「专业、克制、可信」基调:无夸张动效,状态切换以淡入/位移为主(120–160ms),不使用弹跳、闪烁、炫光。
> 所有颜色、字号、间距引用《设计系统》规范,本文不再重复定义。

---

## 0. 通用约定

| 项 | 约定 |
|---|---|
| 页面参数传递 | 通过 URL query 传递,如 `?clueId=XF2026-0731&tab=rules` |
| 主操作按钮 | 政务蓝实心(`#1D5A99`),一屏最多一个 |
| 次操作 / 取消 | 白底描边 |
| 危险操作(退回/删除) | 二次确认弹窗,确认按钮用高风险红 `#C0392B` |
| 动效时长 | 抽屉滑入 200ms、淡入 120ms、悬浮反馈即时 |
| 键盘 | 弹窗/抽屉支持 `Esc` 关闭;表格行支持 `↑↓` 移动、`Enter` 打开详情 |
| 权限 | 无权限的操作按钮置灰(45% 透明度)并悬浮提示「无操作权限」,不隐藏 |

## 2. 列表 / 图表的加载态、空态、错误态

对所有数据区域(表格、卡片、图表)统一四态:**加载中 → 有数据 / 空 / 错误**。容器尺寸在四态间保持不变,避免布局跳动。

### 2.1 加载态(Loading)

- **表格**:表头正常显示,表体渲染 5–8 行**骨架行**——每格一条 `#EAEEF3` 灰条(宽度 40%–80% 随列变化),1.2s 呼吸式明暗循环(透明度 100%↔60%),不使用旋转 spinner。
- **指标卡 / KPI**:数值位置显示等宽灰条,标签正常显示。
- **图表**:绘图区显示居中的浅灰占位 + 文案「加载中…」(`#97A3B0`);坐标轴可先行绘制。
- **抽屉 / 面板**:标题区正常,内容区骨架块。
- 超过 8s 未返回:转为「加载较慢」提示 + 「重试」链接,但不判定为错误。

### 2.2 空态(Empty)

容器居中,竖排:细描边线性图标(48px,`#BCC5D0`)+ 主文案(14px `#4C5A68`)+ 辅助说明(13px `#6E7C8B`)+(可选)操作按钮。

| 场景 | 主文案 | 操作 |
|---|---|---|
| 线索列表无匹配 | 未查询到符合条件的风险线索 | 「重置筛选条件」 |
| 列表本就无数据 | 暂无风险线索 | — |
| 图表无数据 | 所选周期暂无数据 | 「切换周期」 |
| 图谱无关联 | 该主体暂无关联关系 | — |
| 引用来源为空 | 本次回答未引用具体文号 | — |
| 抽屉某标签页无内容 | 暂无处置记录 | 「填写核查结果」 |

- 区分「筛选后为空」(提示可重置筛选)与「本无数据」(不提示重置)。

### 2.3 错误态(Error)

- **整块加载失败**:容器居中显示 `#C0392B` 警示图标 + 「数据加载失败」+ 简要原因(如「网络异常 / 服务暂不可用」)+「重试」按钮(白底描边)。
- **局部失败**(如图表失败但 KPI 成功):仅该区块显示错误态,其余正常。
- **无权限**:显示「无权限查看该数据」,图标用中性灰,不显示重试。
- 错误文案面向业务人员,不暴露堆栈/错误码;错误码折叠在「详情」中供运维排查。

## 3. 表单校验规则与提示位置

### 通用规则
- **校验时机**:失焦(blur)即时校验单字段;点击「保存/提交」时整表校验。
- **提示位置**:错误信息显示在字段**正下方**(12px,`#C0392B`),字段边框转 `#C0392B`;不使用 alert 弹窗承载字段级错误。
- **整表错误**:表单顶部显示汇总条(`#F8E8E6` 底 / `#8E2A20` 字):「共 N 项未通过校验,请检查标红项」,并自动滚动/聚焦到第一个错误字段。
- **成功**:保存成功以右上角轻量 toast 提示(3s 自动消失,`#2E8757`),不打断操作。

### 3.1 规则库配置 — 规则编辑

| 字段 | 规则 | 提示 |
|---|---|---|
| 规则名称 | 必填,2–50 字,同库内唯一 | 「请输入规则名称」/「名称已存在」 |
| 规则类别 | 必选 | 「请选择规则类别」 |
| 风险等级 | 必选(高/中/低) | 「请选择风险等级」 |
| 判定条件 | 至少 1 条;每条字段、运算符、阈值均必填;阈值为数值型时校验数字与范围 | 缺项行标红,行下提示「请完善判定条件」 |
| 调度频率 | 必选 | 「请选择调度频率」 |
| 启用开关 | 开启前必须已通过整表校验 | 未通过时禁止开启并提示「请先完善并保存规则」 |
| 测试运行 | 需先填满判定条件方可点击 | 未满足时按钮置灰 |

### 3.2 风险线索工作台 — 处置结果回填(抽屉内)

| 字段 | 规则 | 提示 |
|---|---|---|
| 核查结论 | 必选 | 「请选择核查结论」 |
| 补缴税款(元) | 结论为「需补缴」时必填;数字,≥0,最多 2 位小数 | 「请输入补缴税款金额」/「金额格式不正确」 |
| 滞纳金(元) | 选填;数字,≥0 | 「金额格式不正确」 |
| 处理意见 | 必填,≥10 字 | 「请填写处理意见(不少于 10 字)」 |
| 附件 | 结论为「需补缴/移送」时必传;单文件 ≤20MB;pdf/jpg/png | 「请上传核查佐证材料」/「文件格式或大小不符」 |
| 提交处置 | 整表通过后可点击;提交前弹二次确认 | — |
| 保存草稿 | 不做必填校验,仅校验已填字段格式 | — |

## 4. 弹窗(Modal)与抽屉(Drawer)

### 4.1 详情抽屉(风险线索工作台)

- **触发**:点击表格行 / 行内「详情」/ 线索编号。
- **形态**:从右侧滑入(200ms),宽 508px,覆盖于列表之上(列表不重排),带左侧投影;列表当前行高亮保持。
- **切换**:抽屉打开时点击另一行,内容原地刷新(不关闭再开)。
- **关闭**:① 右上角 ✕;② `Esc`;③ 点击抽屉以外的列表区域;④ 完成「提交处置」后自动关闭并刷新该行状态。
- **未保存保护**:回填表单有改动时关闭,弹二次确认「有未保存的内容,确定离开?」。

### 4.2 节点详情面板(关联图谱)

- 常驻右侧,非浮层;随选中节点刷新,不可关闭(未选中时显示根节点)。

### 4.3 确认类弹窗(Modal)

| 触发 | 标题 | 确认按钮 |
|---|---|---|
| 行内 / 批量「派发」 | 确认派发 N 条线索? | 政务蓝「确认派发」 |
| 「退回」 | 确认退回?需填写退回理由 | 高风险红「确认退回」(理由必填,否则禁用) |
| 批量删除 / 停用规则 | 危险操作确认 | 高风险红 |
| 「新会话」 | 清空当前对话? | 政务蓝「确认」 |
| 离开有未保存表单 | 放弃未保存的修改? | 政务蓝「离开」/ 白底「继续编辑」 |

- **形态**:居中,宽约 440px,4px 圆角,半透明遮罩(`#1C2733` 50%),`#5FA8D3` 无。
- **关闭**:确认 / 取消 / ✕ / `Esc`;遮罩点击**不**关闭确认类弹窗(防误触),仅信息类弹窗可点遮罩关闭。
- **加载**:确认按钮点击后进入 loading(按钮内联,禁止重复提交),完成后关闭 + toast。

### 4.4 下拉 / 气泡

- 区县、类别、周期等下拉:点击展开,再次点击或点击外部收起,`Esc` 收起;单选即时生效,多选需底部「确定」。

# Handoff: 决策分析模块(4 页)· 税务风险智能分析平台

## Overview
政务内网 Web 管理系统「智慧综合治税与税收风险智能分析平台」的决策分析模块,共 4 个页面:

1. **收入分析** — 收了多少、进度赶上没、增长是谁贡献的
2. **税源分析** — 谁在交税、分布如何、集中度多高、税源流入/流出
3. **治税成效分析** — 规则命中→线索→核查→定性→入库的闭环成效
4. **专题分析** — 按专题(房地产/建筑安装/平台经济)切换整个视图

用户是税务干部,在 ≥1440px 桌面浏览器中办公使用。

## About the Design Files
本包中的 `.dc.html` 文件是**用 HTML 制作的设计参考(高保真原型)**,不是可直接上线的生产代码。任务是**在目标代码库的既有技术栈中(React/Vue 等)按其既有模式重新实现这些设计**;若尚无代码库,请为该项目选择合适框架(推荐 React + 任一图表库,或纯 SVG 复刻)。原型在浏览器直接打开即可运行(依赖同目录 `support.js` 运行时,仅用于预览)。数据均为演示假数据,实现时替换为接口数据。

## Fidelity
**High-fidelity。** 颜色、字号、间距、交互状态均为最终意图,应按像素级复刻(可映射到代码库的等价 token/组件)。

## Interactions & Behavior
详见随附《交互说明.md》(全平台规范:四态、表单校验、弹窗/抽屉、状态色)。本模块要点:
- 悬停反馈即时;下拉、tab、排序、分页、节点/环节/平台选中均为本地 state,无路由跳转。
- 排序:首次点击数值列降序,再点切换方向;切换排序时收起展开行/回到第 1 页。
- 筛选下拉互斥展开(开一个关另一个),选中即收起。
- 侧栏跳转:四页通过侧栏「决策分析」互链(原型中为相对路径 `window.location`;实现时替换为路由)。
- 动效克制:120–160ms 淡入/位移,无弹跳闪烁。

## State Management
每页本地 state:`openGroups`(侧栏折叠)、`timeVal/distVal + open` 标志(筛选)、`tip`(tooltip 内容与坐标)。另:收入分析 `sortKey/sortDir/expanded`;治税成效 `stage/tab/page/sortKey/sortDir`;专题分析 `topic/reSel/platSel`。数据获取:各图表/表格按 时间范围+区县 两个全局筛选参数请求。
